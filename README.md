# Skill Exchange Hub

You are building a startup-grade product called EXCHANGE.

EXCHANGE is not an online course marketplace.

It is a student skill exchange infrastructure where university students exchange knowledge using internal credits and build verified skill reputation.

Core philosophy:

Students don't pay money first.

They exchange value.

A student can:

- learn a skill from another student

- teach a skill they already have

- earn internal credits

- build a verified Skill Passport

The product combines:

- LinkedIn professional identity

- Airbnb trust system

- Duolingo progress psychology

- Notion clean workspace

Target users:

University students.

Initial pilot:

Universitas Indonesia students across faculties.

The website must feel:

- professional

- trustworthy

- modern

- ambitious

Avoid:

- generic LMS design

- online course marketplace appearance

- childish education visuals

Before coding, understand the product philosophy.
